## Dataset Preparation

### Converting Replicator Output to Training Format

Isaac Sim Replicator outputs NumPy arrays for annotations. Most training frameworks expect specific formats:

- **YOLOv8**: Text files with normalized bounding boxes
- **Detectron2**: COCO JSON format
- **PyTorch**: Custom dataset loaders

### Example: YOLO Format Conversion

```python title="convert_to_yolo.py"
import numpy as np
from PIL import Image
import os

dataset_dir = "./synthetic_mugs"
output_dir = "./yolo_dataset"
os.makedirs(f"{output_dir}/images/train", exist_ok=True)
os.makedirs(f"{output_dir}/labels/train", exist_ok=True)

# Process each image
for i in range(1000):
    # Load RGB image
    img_path = f"{dataset_dir}/rgb_{i:04d}.png"
    img = Image.open(img_path)
    img_width, img_height = img.size

    # Load bounding boxes [x_min, y_min, x_max, y_max]
    bbox_path = f"{dataset_dir}/bounding_box_2d_tight_{i:04d}.npy"
    bboxes = np.load(bbox_path)

    # Convert to YOLO format: [class_id, x_center, y_center, width, height] (normalized)
    yolo_labels = []
    for bbox in bboxes:
        x_min, y_min, x_max, y_max = bbox

        # Normalize to [0, 1]
        x_center = ((x_min + x_max) / 2) / img_width
        y_center = ((y_min + y_max) / 2) / img_height
        width = (x_max - x_min) / img_width
        height = (y_max - y_min) / img_height

        class_id = 0  # "mug" class
        yolo_labels.append(f"{class_id} {x_center:.6f} {y_center:.6f} {width:.6f} {height:.6f}")

    # Save image
    img.save(f"{output_dir}/images/train/{i:04d}.jpg")

    # Save labels
    with open(f"{output_dir}/labels/train/{i:04d}.txt", 'w') as f:
        f.write('\n'.join(yolo_labels))

print(f"Converted {1000} images to YOLO format!")
```

### Dataset Configuration

Create `dataset.yaml` for YOLOv8:

```yaml title="dataset.yaml"
path: ./yolo_dataset
train: images/train
val: images/val

nc: 1  # Number of classes
names: ['mug']
```

## Training YOLOv8 on Synthetic Data

### Installation

```bash
pip install ultralytics torch torchvision
```

### Training Script

```python title="train_yolo.py"
from ultralytics import YOLO

# Load pretrained YOLO model
model = YOLO('yolov8n.pt')  # Nano model (fastest)

# Train on synthetic data
results = model.train(
    data='dataset.yaml',
    epochs=50,
    imgsz=640,
    batch=16,
    device=0,  # GPU 0
    project='runs/detect',
    name='mug_detector',
    patience=10,  # Early stopping
    save=True,
    plots=True
)

# Evaluate
metrics = model.val()
print(f"mAP50: {metrics.box.map50:.3f}")
print(f"mAP50-95: {metrics.box.map:.3f}")
```

## Evaluation Metrics

### Key Metrics Explained

**1. Precision**:
- Of all predictions labeled "mug", what % were actually mugs?
- High precision = few false positives

**2. Recall**:
- Of all actual mugs, what % did we detect?
- High recall = few false negatives

**3. mAP50** (mean Average Precision @ IoU=0.5):
- Average precision across all classes at 50% overlap threshold
- Standard metric for object detection

**4. mAP50-95**:
- Average mAP at IoU thresholds from 50% to 95%
- Stricter metric (requires precise bounding boxes)

## Deploying Models into Isaac Sim

### Real-Time Inference in Simulation

```python title="deploy_yolo_isaac.py"
from omni.isaac.kit import SimulationApp
simulation_app = SimulationApp({"headless": False})

from omni.isaac.core import SimulationContext
from omni.isaac.sensor import Camera
import cv2
import numpy as np
from ultralytics import YOLO

# Load trained model
model = YOLO('runs/detect/mug_detector/weights/best.pt')

# Create simulation
sim_context = SimulationContext()
sim_context.add_default_ground_plane()

# Add camera
camera = Camera(
    prim_path="/World/Camera",
    position=[2.0, 0.0, 1.5],
    resolution=(640, 480),
    frequency=10  # 10 Hz
)

# Start simulation
sim_context.play()

# Inference loop
while simulation_app.is_running():
    sim_context.step(render=True)

    # Get camera image
    rgb_data = camera.get_rgba()[:, :, :3]  # Drop alpha channel

    # Run YOLO inference
    results = model.predict(rgb_data, verbose=False)

    # Draw bounding boxes
    annotated_frame = results[0].plot()

    # Display
    cv2.imshow("YOLO Detections", cv2.cvtColor(annotated_frame, cv2.COLOR_RGB2BGR))
    cv2.waitKey(1)

simulation_app.close()
```

**Result**: Real-time object detection running inside Isaac Sim!

## Sim-to-Real Transfer Evaluation

### Testing on Real Images

```python title="test_real_images.py"
from ultralytics import YOLO
import glob

model = YOLO('runs/detect/mug_detector/weights/best.pt')

# Test on real photos
real_images = glob.glob("real_mug_photos/*.jpg")

for img_path in real_images:
    results = model.predict(img_path, save=True, conf=0.5)
    print(f"{img_path}: {len(results[0].boxes)} mugs detected")
```

### Common Sim-to-Real Issues

| Issue | Cause | Solution |
|-------|-------|----------|
| Low recall on real data | Synthetic textures too uniform | Increase texture randomization |
| False positives | Backgrounds too simple | Add clutter, complex scenes |
| Poor lighting adaptation | Only trained on bright scenes | Randomize lighting intensity |
| Size estimation errors | Camera FOV mismatch | Match synthetic camera specs to real |

## Fine-Tuning on Real Data

If sim-to-real gap is large, fine-tune with small real dataset:

```python
# 1. Train on 10k synthetic images (as shown above)
# 2. Fine-tune on 100 real images

model = YOLO('runs/detect/mug_detector/weights/best.pt')  # Load synthetic-trained model

model.train(
    data='real_dataset.yaml',  # Small real dataset
    epochs=20,
    imgsz=640,
    batch=8,
    lr0=0.0001,  # Lower learning rate for fine-tuning
    freeze=10  # Freeze first 10 layers
)
```

**Typical Improvement**: +10-20% mAP on real data with just 100 real images!

## Advanced: Semantic Segmentation with Mask R-CNN

For pixel-precise masks:

```python
from detectron2.engine import DefaultTrainer
from detectron2.config import get_cfg
from detectron2 import model_zoo

cfg = get_cfg()
```
