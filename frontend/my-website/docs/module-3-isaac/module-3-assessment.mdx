## Part 2: Hands-On Capstone Project (60 points)

### Project: End-to-End Isaac Sim Robot Intelligence Pipeline

**Objective**: Build a complete robot AI system that:
1. Generates synthetic training data
2. Trains a perception model (object detection)
3. Trains an RL policy (object retrieval)
4. Integrates both with a behavior tree
5. Deploys to a ROS 2-controlled simulated robot

**Scenario**: A humanoid robot must navigate to a table, detect a specific object (mug), grasp it, and deliver it to a target location.

---

### Task Breakdown

#### Task 1: Synthetic Data Generation (10 points)

**Requirements**:
- Use Isaac Sim Replicator to generate 500 images of mugs on tables
- Apply domain randomization:
  - Random object poses (position, rotation, scale)
  - Random lighting (intensity, color temperature)
  - Random textures (at least 3 different mug materials)
- Export annotations: RGB images + 2D bounding boxes (COCO format)

**Deliverables**:
- Python script: `generate_dataset.py`
- Output folder: `./mug_dataset/` with 500 images + annotations
- README: Explain randomization parameters

**Evaluation Criteria**:
- [ ] 500 images generated successfully (2 pts)
- [ ] Bounding box annotations accurate (>90% IoU) (3 pts)
- [ ] Visible randomization diversity (lighting, poses, textures) (3 pts)
- [ ] COCO JSON format valid (2 pts)

---

#### Task 2: Perception Model Training (15 points)

**Requirements**:
- Train YOLOv8 nano model on synthetic mug dataset
- Achieve >80% mAP50 on validation set (20% split)
- Export trained model to ONNX format
- Test inference speed: must achieve >10 FPS on GPU

**Deliverables**:
- Training script: `train_yolo.py`
- Trained model: `mug_detector.onnx`
- Evaluation report: `results.txt` (mAP, precision, recall, FPS)

**Evaluation Criteria**:
- [ ] Training completes without errors (3 pts)
- [ ] mAP50 > 0.80 on validation set (5 pts)
- [ ] ONNX export successful and inference works (4 pts)
- [ ] Inference speed >10 FPS (3 pts)

---

#### Task 3: RL Policy Training (Navigation) (15 points)

**Requirements**:
- Train a navigation policy in Isaac Gym
- Robot must reach target waypoints within 2 meters radius
- Train with 2048 parallel environments for 500 epochs
- Curriculum: Start with close waypoints (1m), increase to 5m

**Deliverables**:
- Training script: `train_navigation.py`
- Trained policy: `navigation_policy.pth`
- Training curves: TensorBoard logs in `runs/navigation/`
- Video: 30-second clip of trained policy navigating (5 random waypoints)

**Evaluation Criteria**:
- [ ] Training runs without GPU memory errors (3 pts)
- [ ] Policy successfully reaches waypoint >80% of time (5 pts)
- [ ] Smooth navigation (no excessive spinning or falling) (4 pts)
- [ ] TensorBoard shows clear learning progress (3 pts)

---

#### Task 4: Behavior Tree Integration (10 points)

**Requirements**:
- Create a behavior tree using Isaac Cortex:
  ```
  Sequence:
    1. Navigate to table (RL policy)
    2. Detect mug (YOLO model)
    3. Grasp mug (scripted action)
    4. Navigate to delivery point (RL policy)
    5. Release mug
  ```
- Handle failures: If detection fails, retry 3 times before aborting
- If navigation fails (stuck for >10 seconds), request new waypoint

**Deliverables**:
- Behavior tree implementation: `behavior_tree.py`
- Visualization: PNG diagram of tree structure
- Success log: `bt_execution.log` showing node status per tick

**Evaluation Criteria**:
- [ ] Tree executes all 5 steps in sequence (4 pts)
- [ ] Retry logic works for detection failures (2 pts)
- [ ] Navigation timeout handling implemented (2 pts)
- [ ] Tree visualization clear and accurate (2 pts)

---

#### Task 5: ROS 2 Deployment (10 points)

**Requirements**:
- Create ROS 2 nodes:
  - `mug_detector_node`: Subscribes to `/camera/image_raw`, publishes `/detections`
  - `navigation_policy_node`: Subscribes to `/joint_states`, publishes `/joint_command`
  - `behavior_tree_node`: Orchestrates both nodes
- Test in Isaac Sim with ROS 2 Bridge enabled
- Record rosbag: 60 seconds of full task execution

**Deliverables**:
- ROS 2 package: `mug_delivery_robot/`
- Launch file: `mug_delivery.launch.py` (starts all 3 nodes)
- Rosbag: `task_execution.bag`
- Performance report: Latency (camera→detection), success rate

**Evaluation Criteria**:
- [ ] All 3 ROS 2 nodes launch without errors (3 pts)
- [ ] Nodes communicate correctly (topics match, data flows) (3 pts)
- [ ] Rosbag captures full task execution (2 pts)
- [ ] End-to-end latency &lt;100ms (2 pts)
