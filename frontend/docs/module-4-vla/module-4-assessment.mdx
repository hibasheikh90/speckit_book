### Section B: Short Answer (10 questions × 2 points = 20 points)

#### Question 21
**Explain the three main components of a VLA model and their roles. (4-5 sentences)**

<details>
<summary>Sample Answer</summary>
VLA models consist of three components: (1) Vision Encoder (e.g., CLIP, DINO) extracts semantic features from camera images, outputting 512-1024 dimensional embeddings. (2) Language Model (e.g., T5, BERT) encodes natural language instructions into embeddings aligned with vision. (3) Action Decoder (typically a Transformer) fuses vision and language features to generate robot actions (joint angles, gripper states). These components work together: vision understands "what's in the scene," language understands "what to do," and the decoder outputs "how to do it."
</details>

---

#### Question 22
**What is behavior cloning and why is it the primary training method for VLA models? (3-4 sentences)**

<details>
<summary>Sample Answer</summary>
Behavior cloning is supervised imitation learning where the model learns to mimic human demonstrations by minimizing the difference between predicted and demonstrated actions. It's ideal for VLA because it leverages human expertise (teleoperators show the robot how to perform tasks) and requires no reward engineering. The model learns directly from (observation, instruction, action) tuples collected from demonstrations. However, behavior cloning can suffer from distribution shift when the robot encounters states not seen during training.
</details>

---

#### Question 23
**How does RT-2 differ from RT-1 in terms of architecture and capabilities? (4-5 sentences)**

<details>
<summary>Sample Answer</summary>
RT-1 uses separate vision (EfficientNet) and language (USE) encoders with FiLM conditioning, trained only on robot demonstrations. RT-2 leverages pre-trained Vision-Language Models (VLMs like PaLI-X) that were trained on billions of web images and text pairs. This pre-training gives RT-2 emergent capabilities—it can perform tasks never seen in robot data (like "pick up extinct animal") by transferring knowledge from internet images. RT-2 achieves 62% success on novel tasks versus 32% for RT-1.
</details>

---

#### Question 24
**Describe domain randomization and its importance for sim-to-real transfer. (3-4 sentences)**

<details>
<summary>Sample Answer</summary>
Domain randomization applies random variations to simulation parameters during training—randomizing lighting, textures, object masses, friction, and camera noise. This forces the VLA to learn robust features that work across diverse conditions rather than overfitting to perfect simulation. When deployed to the real world, the robot has seen enough variation that reality appears as "just another randomization." This technique improves sim-to-real transfer from 10-20% to 60-80% success rates.
</details>

---

#### Question 25
**What is the Open X-Embodiment dataset and why is it important for VLA research? (3-4 sentences)**

<details>
<summary>Sample Answer</summary>
Open X-Embodiment is the largest open dataset for robot learning, containing 970,000 demonstrations from 22 different robot platforms performing diverse manipulation and navigation tasks. Before this dataset, each lab trained separate models on limited data (10k-100k demos) that didn't transfer between robots. Open X-Embodiment enables training true "foundation models" that generalize across robot morphologies, tasks, and environments. It democratizes VLA research by providing standardized, large-scale data.
</details>

---

#### Question 26
**List and explain three challenges when deploying VLA models to humanoid robots. **

<details>
<summary>Sample Answer</summary>
1. **High dimensionality**: Humanoids have 30-50+ DOF versus 7-DOF for robot arms, making action spaces exponentially larger and harder to learn.
2. **Balance constraints**: Unlike fixed-base arms, humanoids must maintain balance during manipulation, requiring whole-body coordination and Center of Mass (CoM) monitoring.
3. **Computational constraints**: VLA models (7B+ parameters) require powerful GPUs, but humanoids have limited onboard compute (Jetson Orin), necessitating model compression (TensorRT) and optimization.
</details>

---

#### Question 27
**Explain the difference between CLIP and DINOv2 vision encoders. When would you use each?**

<details>
<summary>Sample Answer</summary>
CLIP is trained with contrastive learning to align images and text captions, making it ideal for VLA because it naturally grounds language to vision. DINOv2 uses self-supervised learning without text, learning visual features through self-distillation. Use CLIP when language grounding is critical (e.g., "find the red object"). Use DINOv2 when you need pure visual features for tasks like dense prediction, segmentation, or when training data lacks language annotations. Both can be combined for complementary strengths.
</details>

---

#### Question 28
**What are the three stages in the VLA training pipeline? Briefly describe each.**

<details>
<summary>Sample Answer</summary>
1. **Pre-training**: Train vision-language backbone (e.g., CLIP) on billions of web (image, caption) pairs to learn general visual and semantic understanding.
2. **Robot demonstration collection**: Gather robot interaction data through teleoperation, kinesthetic teaching, or scripted policies, creating (observation, instruction, action) tuples.
3. **Imitation learning (behavior cloning)**: Fine-tune the pre-trained model on robot demonstrations using supervised learning to predict actions given observations and instructions. Optional: further improve with reinforcement learning.
</details>

---

#### Question 29
**How does bimanual coordination work in VLA systems? Describe two strategies.**

<details>
<summary>Sample Answer</summary>
**Strategy 1: Joint Policy** - Both arms are controlled by a single policy that models their actions together with cross-attention, enabling coordinated movements and preventing collisions. Trained on synchronized bimanual demonstrations.
**Strategy 2: Leader-Follower** - One arm executes the primary task (leader) while the other supports or maintains constraints (follower). For example, "hold box with left hand, screw lid with right hand." Asymmetric but simpler to train than fully joint policies.
</details>

---

#### Question 30
**What is TensorRT and why is it critical for deploying VLA models on robots? (2-3 sentences)**

<details>
<summary>Sample Answer</summary>
TensorRT is NVIDIA's deep learning inference optimizer that converts PyTorch/ONNX models into optimized GPU kernels. It reduces VLA inference latency by 2-10x through layer fusion, precision calibration (FP16/INT8), and kernel auto-tuning. For robots, this is critical because it enables real-time control (>10 Hz) of large VLA models (7B parameters) on embedded GPUs like Jetson Orin.
</details>

#### 2. Vision Encoder Node (10 points)

**File**: `vision_encoder_node.py`

**Requirements**:
- Subscribe to `/camera/image_raw` (Image)
- Load pre-trained CLIP vision encoder (ViT-B/32)
- Encode RGB images to 512-dim embeddings
- Publish to `/vision/embeddings` (Float32MultiArray)
- Run at 10 Hz (handle 30 Hz camera with downsampling)
- Parameters:
  - `model_name`: "ViT-B/32"
  - `device`: "cuda" or "cpu"

**Evaluation**:
- [2 pts] Correct topic subscription/publishing

- [2 pts] Runs at 10 Hz target

#### 4. VLA Policy Node (20 points)

**File**: `vla_policy_node.py`

**Requirements**:
- Subscribe to:
  - `/vision/embeddings` (Float32MultiArray)
  - `/language/embeddings` (Float32MultiArray)
  - `/robot/joint_states` (JointState)
- Simple fusion policy:
  - Concatenate vision + language embeddings
  - 2-layer MLP: [1024] → [512] → [256] → [7-DOF action]
- Publish to `/robot/action` (Float64MultiArray)
- Behavior:
  - For "pick" commands: output reaching action
  - For "place" commands: output placing action
  - Use simple rule-based mapping (simplified VLA)
- Run at 10 Hz

**Evaluation**:
- [4 pts] All subscriptions configured correctly
- [4 pts] Multimodal fusion (vision + language)
- [4 pts] Action generation logic
- [4 pts] Handles different command types
- [4 pts] Publishes actions at correct rate

#### 5. Robot Controller Node (10 points)

### Testing and Validation

**Test Sequence**:

```bash
# Terminal 1: Launch Isaac Sim (or Gazebo) with robot
ros2 launch isaac_sim robot_manipulation.launch.py

# Terminal 2: Launch VLA system
ros2 launch vla_manipulation vla_system_launch.py

# Terminal 3: Verify all nodes running
ros2 node list
# Expected: /vla_manipulation/vision_encoder
#           /vla_manipulation/language_encoder
#           /vla_manipulation/vla_policy
#           /vla_manipulation/robot_controller

# Terminal 4: Test vision encoding
ros2 topic echo /vla_manipulation/vision/embeddings

# Terminal 5: Send language commands
ros2 topic pub /vla_manipulation/task/command std_msgs/msg/String \
    "{data: 'pick up the red cube'}"

# Wait 2 seconds, observe robot motion

ros2 topic pub /vla_manipulation/task/command std_msgs/msg/String \
    "{data: 'place the cube on the shelf'}"

# Terminal 6: Monitor robot actions
ros2 topic echo /vla_manipulation/robot/action
```

**Expected Behavior**:
1. Vision encoder publishes 512-dim embeddings at 10 Hz
2. Language command triggers language encoder
3. VLA policy fuses vision + language → outputs 7-DOF action
4. Robot controller executes safe motion
5. Robot reaches toward object on "pick" command
6. Gripper closes when grasping
7. Robot moves to shelf on "place" command
