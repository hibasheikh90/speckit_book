# Welcome to Physical AI & Humanoid Robotics

An **AI-native, bilingual textbook** designed to take you from ROS 2 fundamentals to building autonomous humanoid robot systems.

## 🎯 What You'll Learn

This comprehensive textbook covers the complete robotics stack needed for modern Physical AI and humanoid robotics:

## 📚 5 Comprehensive Modules

### Module 1: ROS 2 Fundamentals
**Duration**: 4 weeks | **Chapters**: 8

Master the Robot Operating System 2 (ROS 2) - the industry-standard framework for robot software development.

**You'll learn**:
- Writing publisher/subscriber nodes for asynchronous communication
- Implementing services for request-response patterns
- Creating actions for long-running, preemptable tasks
- Building launch files for complex multi-node systems

[Start Module 1 →](/docs/module-1-ros2/week-1/chapter-1-intro)

---

### Module 2: Digital Twin Simulation
**Duration**: 3 weeks | **Chapters**: 6

Create high-fidelity digital twins of robots using Gazebo and Unity for safe, scalable testing.

**You'll learn**:
- Building robot models with URDF/Xacro
- Integrating Gazebo physics engines with ROS 2
- Developing Unity simulations with ROS-TCP-Connector
- Implementing humanoid animation and physics

[Start Module 2 →](/docs/module-2-simulation/week-5/chapter-9-intro-gazebo)

---

### Module 3: NVIDIA Isaac Platform
**Duration**: 4 weeks | **Chapters**: 8

Leverage NVIDIA's cutting-edge platform for synthetic data generation and reinforcement learning.

**You'll learn**:
- Generating photorealistic synthetic datasets with Isaac Sim
- Training perception models with domain randomization
- Using Isaac Gym for parallel RL training
- Deploying trained policies to real robots

[Start Module 3 →](/docs/module-3-isaac/week-8/chapter-15-intro-isaac)

---

### Module 4: Vision-Language-Action (VLA) Robotics
**Duration**: 3 weeks | **Chapters**: 6

Implement state-of-the-art VLA models that enable robots to understand natural language and execute complex tasks.

**You'll learn**:
- Vision encoders (CLIP, DINO) for robot perception
- Language-conditioned control with GPT-4 and PaLM-E
- Training VLA models with imitation learning
- Deploying VLA models on humanoid robots

[Start Module 4 →](/docs/module-4-vla/week-12/chapter-23-intro-vla)

---

### Module 5: Capstone - Autonomous Humanoid Robot
**Duration**: 2 weeks | **Chapters**: 4

Integrate everything you've learned to build a complete autonomous humanoid robot system.

**You'll learn**:
- System architecture design and integration
- Multi-module coordination (perception → planning → control)
- Testing strategies from unit tests to sim-to-real transfer
- Deployment and continuous improvement

[Start Module 5 →](/docs/module-5-capstone/week-15/chapter-29-capstone-overview)

## 🚀 Getting Started

### Prerequisites

Before starting, ensure you have:

1. **Basic Programming**: Python fundamentals (variables, functions, classes)
2. **Linux Familiarity**: Command-line basics (cd, ls, mkdir)
3. **Hardware**: 8GB RAM, quad-core CPU, Ubuntu 22.04 LTS
4. **Software**: ROS 2 Humble (installation covered in Module 1)

[View Full Prerequisites →](/docs/prerequisites)

### Learning Path

**Recommended Timeline**: 16 weeks (10-15 hours/week)

1. **Week 1-4**: Module 1 - ROS 2 Fundamentals
2. **Week 5-7**: Module 2 - Digital Twin Simulation
3. **Week 8-11**: Module 3 - NVIDIA Isaac Platform
4. **Week 12-14**: Module 4 - VLA Robotics
5. **Week 15-16**: Module 5 - Capstone Project

**Flexible Learning**: Each module is self-contained. You can skip to advanced modules if you already have foundational knowledge.
