# Prerequisites & Setup

Before starting this textbook, ensure you meet the prerequisites and complete the necessary setup steps.

---

## 📋 Prerequisite Knowledge

### 1. Programming Fundamentals

**Required**:
- Basic Python (variables, functions, loops, conditionals, classes)
- Understanding of object-oriented programming concepts
- Familiarity with Python standard library

**Recommended**:
- Experience with NumPy for numerical operations
- Basic understanding of asynchronous programming
- Exposure to C++ (helpful for ROS 2, but not required)

### 2. Linux Command Line

**Required**:
- Navigate directories (`cd`, `ls`, `pwd`)
- Create/delete files and folders (`mkdir`, `rm`, `touch`)
- Edit files with text editors (`nano`, `vim`, or VSCode)
- Understand file permissions (`chmod`)
- Use package managers (`apt`, `pip`)

**Recommended**:
- Shell scripting basics (bash)
- Understanding of environment variables (`export`, `source`)
- Experience with `ssh` for remote connections

### 3. Version Control (Git)

**Required**:
- Clone repositories (`git clone`)
- Commit changes (`git add`, `git commit`)
- Push/pull from remote repositories

**Recommended**:
- Branching and merging
- Resolving merge conflicts
- Using `.gitignore`

### 4. Mathematics

**Required**:
- Basic linear algebra (vectors, matrices, matrix multiplication)
- Trigonometry (sine, cosine, angles, radians)
- Basic calculus (derivatives, integrals - conceptual understanding)

**Recommended**:
- 3D transformations (rotation matrices, quaternions)
- Probability and statistics (mean, variance, distributions)
- Optimization basics (gradient descent)

## 🖥️ Software Requirements

### 1. Operating System

**Primary**: Ubuntu 22.04 LTS (Jammy Jellyfish)

**Why Ubuntu 22.04?**
- ROS 2 Humble (LTS) officially supports Ubuntu 22.04
- Best compatibility with robotics tools
- Long-term support until 2027

**Alternatives**:
- **Windows** (WSL2): Possible but not recommended (limited GPU passthrough)
- **macOS**: ROS 2 support is experimental (simulation only)
- **Docker**: Can run Ubuntu 22.04 container on any OS

#### Installing Ubuntu 22.04

**Option A: Native Installation** (Recommended)
1. Download Ubuntu 22.04 ISO: [ubuntu.com/download/desktop](https://ubuntu.com/download/desktop)
2. Create bootable USB with [Rufus](https://rufus.ie/) (Windows) or [Etcher](https://www.balena.io/etcher/) (macOS/Linux)
3. Boot from USB and follow installation wizard
4. Allocate at least 50 GB for the partition

**Option B: Dual Boot**
- Keep existing OS and install Ubuntu alongside
- Guide: [Ubuntu Dual Boot Guide](https://help.ubuntu.com/community/DualBoot)

**Option C: Virtual Machine**
- Use VirtualBox or VMware
- Allocate 4+ CPU cores, 8+ GB RAM, 50+ GB storage
- **Note**: Limited performance for simulation/Isaac Sim

### 2. ROS 2 Humble Hawksbill

**Installation** (covered in Module 1, Chapter 2):

```bash
# Update system
sudo apt update && sudo apt upgrade -y

# Setup sources
sudo apt install software-properties-common
sudo add-apt-repository universe
sudo apt update && sudo apt install curl -y
sudo curl -sSL https://raw.githubusercontent.com/ros/rosdistro/master/ros.key -o /usr/share/keyrings/ros-archive-keyring.gpg

# Add ROS 2 repository
echo "deb [arch=$(dpkg --print-architecture) signed-by=/usr/share/keyrings/ros-archive-keyring.gpg] http://packages.ros.org/ros2/ubuntu $(. /etc/os-release && echo $UBUNTU_CODENAME) main" | sudo tee /etc/apt/sources.list.d/ros2.list > /dev/null

# Install ROS 2 Humble Desktop
sudo apt update
sudo apt install ros-humble-desktop -y

# Install development tools
sudo apt install ros-dev-tools -y

# Source ROS 2
echo "source /opt/ros/humble/setup.bash" >> ~/.bashrc
source ~/.bashrc
```

**Verify installation**:
```bash
ros2 doctor
```

### 3. Python 3.10+

Ubuntu 22.04 comes with Python 3.10 pre-installed. Verify:

```bash
python3 --version  # Should show 3.10.x
```

Install additional Python tools:
```bash
sudo apt install python3-pip python3-venv python3-dev -y
```

## 🔧 Troubleshooting Common Issues

### Issue: ROS 2 not found after installation
**Solution**:
```bash
source /opt/ros/humble/setup.bash
echo "source /opt/ros/humble/setup.bash" >> ~/.bashrc
```

### Issue: GPU not detected in Isaac Sim
**Solution**:
```bash
# Check NVIDIA driver
nvidia-smi

# Update driver if needed
sudo ubuntu-drivers autoinstall
```

### Issue: Insufficient disk space
**Solution**:
- Use external SSD/HDD for `~/ros2_ws` workspace
- Clean Docker images: `docker system prune -a`
- Remove unused packages: `sudo apt autoremove`
