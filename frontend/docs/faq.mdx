# Frequently Asked Questions (FAQ)

## General Questions

### What is this textbook about?

This is a comprehensive, AI-native textbook covering the complete stack for building Physical AI and humanoid robot systems. You'll learn ROS 2, digital twin simulation (Gazebo/Unity), NVIDIA Isaac Platform, and Vision-Language-Action (VLA) models through 32 hands-on chapters.

### Is this textbook free?

Yes! This textbook is completely free and open-source under the MIT License. All content, code examples, and diagrams are available on [GitHub](https://github.com/hibasheikh/hackathon_book).

### Do I need a robotics background?

No. This textbook starts from fundamentals in Module 1. You need:
- Basic Python programming
- Linux command-line familiarity
- Basic math (linear algebra, trigonometry)

See [Prerequisites](/docs/prerequisites) for details.

### How long does it take to complete?

**Recommended timeline**: 16 weeks (10-15 hours/week)
- Module 1: 4 weeks
- Module 2: 3 weeks
- Module 3: 4 weeks
- Module 4: 3 weeks
- Module 5: 2 weeks

You can go faster if you already have foundational knowledge.

## Technical Requirements

### What operating system do I need?

**Recommended**: Ubuntu 22.04 LTS (Jammy Jellyfish)

**Why?** ROS 2 Humble (LTS) officially supports Ubuntu 22.04, and it has the best compatibility with robotics tools.

**Alternatives**:
- WSL2 on Windows (limited GPU support)
- macOS (experimental ROS 2 support)
- Docker containers

### Do I need an NVIDIA GPU?

**Not for Modules 1-2**: CPU-only is sufficient for ROS 2 and Gazebo.

**Yes for Modules 3-4**: Isaac Sim and VLA training require NVIDIA GPU with 8 GB+ VRAM.

**Don't have a GPU?** Use cloud options:
- Google Colab (free, limited hours)
- AWS EC2 with GPU instances
- NVIDIA NGC (free access)

See [Prerequisites](/docs/prerequisites#cloud-options) for cloud setup.

### Can I use a virtual machine?

**Yes**, but with limitations:
- **Good for**: Module 1 (ROS 2 basics)
- **Not recommended for**: Module 3 (Isaac Sim requires GPU passthrough, which is complex)

Allocate at least:
- 4+ CPU cores
- 8 GB+ RAM
- 50 GB+ storage

## Learning Path

### Can I skip modules?

**Yes**, if you already have the prerequisite knowledge:

- **Skip Module 1** if you're proficient in ROS 2 Humble
- **Skip Module 2** if you're experienced with Gazebo/Unity simulation
- Each module lists prerequisites at the beginning

**Recommended**: At least skim each module to understand the textbook's teaching approach.

### Are there prerequisites for each module?

**Module 1**: Basic Python, Linux command line
**Module 2**: Module 1 OR existing ROS 2 knowledge
**Module 3**: Modules 1-2 OR ROS 2 + Gazebo experience, NVIDIA GPU
**Module 4**: Modules 1-3 OR robotics + ML experience, GPU
**Module 5**: All previous modules (capstone integrates everything)

### Can I learn from this textbook without a physical robot?

**Absolutely!** The entire curriculum uses simulation:
- **Module 1**: ROS 2 (no hardware needed)
- **Module 2**: Gazebo and Unity simulations
- **Module 3**: Isaac Sim virtual environments
- **Module 4**: VLA models tested in simulation
- **Module 5**: Capstone project in Isaac Sim

Physical robot deployment is optional but recommended for advanced learners.

## Technical Issues

### ROS 2 installation failed. What should I do?

**Common solutions**:

1. **Check Ubuntu version**:
   ```bash
   lsb_release -a  # Should show Ubuntu 22.04
   ```

2. **Update package lists**:
   ```bash
   sudo apt update && sudo apt upgrade -y
   ```

3. **Re-add ROS 2 repository**:
   ```bash
   sudo apt install software-properties-common
   sudo add-apt-repository universe
   ```

4. **Check available disk space**:
   ```bash
   df -h  # Need at least 20 GB free
   ```

See [Module 1, Chapter 2](/docs/module-1-ros2/week-1/chapter-2-setup) for detailed installation guide.

### Gazebo crashes when I launch it

**Common causes**:

1. **Insufficient RAM**: Gazebo requires 4 GB+ RAM
   ```bash
   free -h  # Check available memory
   ```

2. **Graphics drivers**: Update to latest
   ```bash
   sudo ubuntu-drivers autoinstall
   sudo reboot
   ```

3. **Conflicting ROS/Gazebo versions**: Ensure you're using Gazebo Classic 11 with ROS 2 Humble

### Isaac Sim won't detect my GPU

**Solutions**:

1. **Check NVIDIA driver**:
   ```bash
   nvidia-smi  # Should show GPU and driver version
   ```

2. **Update driver** (need 525.60.11+):
   ```bash
   sudo ubuntu-drivers autoinstall
   sudo reboot
   ```

3. **Verify CUDA compatibility**:
   ```bash
   nvcc --version  # Should show CUDA 11.8+
   ```

4. **Use cloud alternative** if local GPU unavailable (see [Prerequisites](/docs/prerequisites#cloud-options))

### Code example not working

**Troubleshooting steps**:

1. **Check environment**:
   ```bash
   source /opt/ros/humble/setup.bash
   echo $ROS_DISTRO  # Should show "humble"
   ```

2. **Verify dependencies installed**:
   ```bash
   rosdep install --from-paths . --ignore-src -y
   ```

3. **Check Python version**:
   ```bash
   python3 --version  # Should be 3.10+
   ```

4. **Review error message** and check "Common Errors" section in the chapter

5. **Still stuck?** [Open a GitHub issue](https://github.com/hibasheikh/hackathon_book/issues) with:
   - Chapter number
   - Error message (full output)
   - System info (`uname -a`, `python3 --version`, `ros2 doctor`)
