## 🎯 Recommended Learning Path

For self-learners who want to supplement this textbook:

1. **Before Module 1**: Complete [Linux Journey](https://linuxjourney.com/) + [Python.org Tutorial](https://docs.python.org/3/tutorial/)
2. **During Module 1**: Watch [Articulated Robotics ROS 2 series](https://youtube.com/@ArticulatedRobotics)
3. **During Module 2**: Read [Modern Robotics textbook](http://hades.mech.northwestern.edu/images/7/7f/MR.pdf) (Ch 1-4)
4. **During Module 3**: Complete [Hugging Face Deep RL Course](https://huggingface.co/deep-rl-course) (Units 1-3)
5. **During Module 4**: Read RT-1 and RT-2 papers ([RT-1](https://arxiv.org/abs/2212.06817), [RT-2](https://arxiv.org/abs/2307.15818))
6. **During Module 5**: Explore [Open X-Embodiment dataset](https://robotics-transformer-x.github.io/)
